FarmDirect 🌾

FarmDirect is a direct farmer-to-buyer agricultural marketplace designed to reduce unnecessary intermediaries, improve farmers' earnings, and provide buyers with transparent product and delivery pricing.

Problem

Multiple intermediaries in the agricultural supply chain reduce farmers' earnings while increasing prices for consumers.

Solution

FarmDirect connects farmers, buyers, and transporters on a single platform.

👨‍🌾 Farmers can list and manage their products.
🛒 Buyers can browse products, place orders, and see estimated delivery costs.
🚚 Transporters can accept delivery jobs and update delivery status.
🗺️ Road distance is calculated using OpenStreetMap, Nominatim, and OSRM.
Tech Stack

Backend: Python, FastAPI, PostgreSQL, SQLAlchemy
Authentication: JWT
Maps: OpenStreetMap, Nominatim, OSRM

Current Features
User registration and login
Role-based access for farmers, buyers, and transporters
Product listing and search
Order management
Inventory management
Delivery assignment and tracking
Delivery cost estimation
Failed delivery and return handling
